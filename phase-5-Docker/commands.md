Образ (Image) - рецепт\чертеж
- неизменяемый - нельзя изменить после создания
- содержит все необходимое для работы приложения: код, библиотеки, настройки, ос
- Хранится в реестре (dockerhub) или локально
Примеры образов:
- ubuntu
- nginx
- python:3.10
- hello-world
Контейнер - испеченный торт или запущенное приложение
- Запущенный экземпляр образа
- Можно создавать много контейнеров из одного образа
- Можно запускать, останавливать, удалять
Пример:
- образ nginx - можно запустить 5 контейнеров с nginx (например для разных сайтов)
- образ python:3.10 - можно запустить контейнер для каждого своего python - скрипта

docker images - посмотреть все скачанные образы
Вывод: 
IMAGE - имя образа 
ID - уникальный идентификатор
DISKUSAGE
CONTENTSIZE - размер образа

docker ps - посмотреть запущенные контейнеры: -a - все
docker run ubuntu bash - запустить контейнер; -it - интерактивный режим; ubuntu - имя образа; bash - что запустить внутри контейнера
