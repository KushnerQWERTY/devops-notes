Block 3

Вывод команды ls -l: -rw-rw-r-- 1 user user 6111 Aug 12 17:57 first-note.txt
1 символ "-" - тип файла, обычно это текст\картинка\скрипт; Также может быть "d" - директория; "l" символическая ссылка (Как ярлык в Windows)
rw-rw-r-- это права доступа - rw- = можно читать и изменять файл (User), второе rw- показывает для Group, r-- для остальных, то есть только чтение. 
далее идет "1" - это количество жестких ссылок (Это когда к одному файлу может вести несколько путей)
user user - первый user - это логин, второй user это группа владельца
далее идет размер файла, дата и имя

Скрипты - расширение .sh
Мы можем менять группы доступа на файлы. chmod +x myscript.sh, после выполнения этой команды, вывод ls -l myscript.sh будет: -rwxrwxr-x ... rwx - означает, что файл можно читать, изменять и запускать, r-x - означает, что можно запускать и читать.
chmod - сhange mode, chown - change owner
chmod 644 "имя файла" - изменение групп доступа: 6(Владелец) - 4(read) + 2(edit) = rw-; 4(Группа) - 4(read) - r--; 4(Остальные) - также как и группа. ! (ЗАПУСКАТЬ НЕТ)
chmod 755 "имя скрипта" для скриптов ( ЗАПУСКАТЬ ДА. Владелец также может изменять)
При отсутствии у скриптов rwx - скрипт будет запрещено запускать - ./hello.sh вывод - Permission Denied, после изменения: chmod 755 hello.sh, вывод ls -l: rwxr-xr-x, что означает, что только владелец может изменять данный скрипт, а остальные только запускать и читать
Если мы хотим запретить остальным запускать наш скрипт, то мы пишем chmod 700 "имя файла/скрипта"
r-- (4) — только чтение (конфиги, логи)
rw- (6) — чтение + запись (личные файлы)
r-x (5) — чтение + запуск (скрипты для всех)
rwx (7) — всё (твои скрипты)
--- (0) — ничего (запрет доступа)

Иногда команды ls недостаточно.

Block 6

id - Вывод покажет UID (номер пользователя), GID (номер группы) и все группы, в которых я состою
sudo useradd "login" - добавление нового пользователя; sudo userdel "login" - удаляет пользователя; если sudo userdel -r "login" - удаляет его домашний каталог вместе с пользователем; также для создания домашней директории для нового пользователя необходим флаг -m: useradd -m "login"
sudo passwd "login" - присвоение пользователю пароля
sudo usermod -aG "группа" "login" - добавление пользователя в группу, -aG - означает добавление; sudo grasswd -d "login" "группа" - удаляет пользователя из группы
su "login" - переключение на другого пользователя
exit - вернуться к предыдущему пользователю
chown - поменять владельца файла
sudo chgrp sudo "namefile" - изменение группы для файла, то есть в данном случае все, кто состоит в группе sudo могут открывать данный файл
! Если создать папку на другом пользователе и присвоить ее другому пользователю, необходимо предоставить ему доступ к пути, по которому возможно попасть к этому файлу или добавить пользователя в группу

Block 7
> - запись или перезаписывание, пример: echo "Hello" > hello.txt - если такого файла не существует, он создаст, если такой файл есть, то он перезапишет все, что там было на "Hello"
>> - добавление, пример: echo "World" >> hello.txt - добавляет информацию к имеющейся, вывод cat hello.txt - Hello/nWorld
| - труба, позволяет объединить команды - ls -l | grep ".txt" - выведет список только текстовых файлов и выделит .txt
