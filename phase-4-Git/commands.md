Git - система контроля версий

git --version 
git config --global user.name "nickname" - Имя исполнителя
git config --global user.emal "nickname@mail.ru" почта исполнителя
Настройки для подписи авторства
git --global --list - список авторов

git init - создание скрытой папки .git в текущей директории. Эта папка является репозиторием.

git status - Отслеживание статуса репозитория. Красным цветом отображаются файлы, которые Git видит, но не отслеживает (untracked)
git add name_files - добавление файла в индекс (staging area), можно также добавить все файлы - git add .
После добавления файлов git status покажет файлы зеленым цветом

git commit -m "Initial commit: added files" - добавление сообщения, зафиксировал файлы, записал имя и почту.
git log - показывает уникальный ID коммита, Автора, Дата и время, содержимое сообщения.

После изменений в файлах репозитория, они будут гореть красным в выводе git status
git diff - Вывод последних изменений
Вывод:
diff --git a/hello.py b/hello.py
--- a/hello.py - удаление
+++ b/hello.py - добавление
@@ -1 +1,2 @@ - показывает, в каких строках файла произошли изменения
-print('hello, devops!')
+print("hello, devops!")
+print("Git is awesome!")

git log --oneline - полная история коммитов
git show HEAD - посмотреть последний коммит
git show (первые 5 символов коммита) - вывод конкретного коммита
git checkout первые 5 символов коммита -- name_file - откат, git взял файл таким, каким он был в указанном коммите

git branch - Вывод всех веток - git branch name_branch - создание ветки - git branch -d name_branch - удаление ветки
* - показывает в какой ветке находишься
git checkout name_branch - переход в ветку - git checkout -b name_branch - создать и перейти
При создании файлов в другой ветке, ее не видно в основной
git merge name_branh - слияние данных из дополнительной ветки в текущую

Иногда Git не может автоматически слить изменения. Это называется конфликт.
Пример:
В ветке main ты изменил строку 5 в hello.py
В ветке feature ты тоже изменил строку 5 в hello.py (по-другому)
При merge Git не знает, какую версию оставить
Git покажет файл с маркерами конфликта
Ты вручную редактируешь файл, оставляя нужную версию (или обе)
Сохраняешь файл и делаешь коммит
